# Reporting security issues

Report vulnerabilities in the Open Waters fork privately to [hello@openwaters.io](mailto:hello@openwaters.io), the contact address published at [openwaters.io/contact](https://openwaters.io/contact/). Include the affected commit SHA, a description of the issue, and reproduction steps. Do not include access tokens or private keys.

Please keep exploit details out of public issues and pull requests while maintainers investigate. Open Waters maintains this fork; reports about it should reach Open Waters rather than the upstream projects.
